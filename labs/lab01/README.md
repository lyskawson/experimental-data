# Lab 01 - Linear regression and Anscombe's quartet

Completed solutions to all three tasks, with a Python notebook, an Excel workbook,
a Polish LaTeX report, and reproducible numerical checks.

## Run the analysis

From the repository root:

```bash
uv sync --locked
uv run python labs/lab01/analysis.py
uv run python -m unittest discover -s labs/lab01 -p 'test_*.py' -v
```

Alternatively, open `solution.ipynb` in VS Code, select the project's `.venv` kernel,
and run all cells. The notebook contains calculations, plots, and explanations for
each task. `analysis.py` implements the formulas and generates the report tables
and figures without accessing the network.

## Methods

Task 1 reports both variance conventions: sample variance uses `ddof=1`, and
population variance uses `ddof=0`. The report's main tables use sample variance.
The spreadsheet computes its own results using formulas, rather than copied
Python outputs.

Task 2 uses the quartet from task 1 as the data referred to by “the previous lab.”
It compares deterministic UTF-8 exports and flags outliers in series III using
Theil-Sen residuals and a normal-scaled MAD, with a threshold of 3.5 and a scale
floor based on the known 0.01 rounding resolution. Filtering runs once and keeps
all original records. The final regressions before and after filtering use OLS.

Task 3 selects `seria1`, `seria9`, and `seria10`: the dinosaur, circle, and bullseye.
The input preserves all 13 series, their order, and their original numeric precision.
Source: [the authors' dataset](https://github.com/jmatejka/same-stats-different-graphs/blob/b4d82f3a2ff8ef5849fecbdfab6dccafccbc1370/samestats/datasets/generated/DatasaurusDozen.tsv).

## Build the PDF and submission archives

Author details are stored only in the local, ignored `report/author.tex` file.
For a fresh clone, copy `report/author.example.tex` to `report/author.tex` and enter
the names, index numbers, and lab group. To compile locally, install TeX Live and
`latexmk`, then run:

```bash
uv run python labs/lab01/package_submission.py
```

The script creates:

- `outputs/report.pdf` - the personalized report.
- `submission/overleaf.zip` - upload this directly to Overleaf as a new project; select pdfLaTeX and `main.tex`.
- `submission/cw1_<index>_<index>.zip` - the ePortal submission, named from the index numbers in `author.tex`.

The submission ZIP includes the PDF at its root, the Overleaf archive, executable
Python sources, the completed notebook, data, exports, the spreadsheet, environment
files, and a SHA-256 manifest. The environment itself, caches, and temporary build
files are excluded. The large screenshot is not needed because the complete verified
CSV is included.

Without local LaTeX, upload the `report/` source files, tables, and images to Overleaf.
The personalized PDF, author file, and submission archives are ignored by Git so
index numbers are not published in the public repository.

Submit the ePortal ZIP before the next lab, unless the instructor specifies a
different deadline. Review the report and conclusions before submitting.
